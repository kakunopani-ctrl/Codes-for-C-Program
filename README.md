Codes-for-C-Program
A repository of beginner-friendly C programs, designed to help learners understand the fundamentals of programming in C. Each program is simple, well-structured, and demonstrates a specific concept such as input/output, conditional statements, arrays, pointers, and functions.

📖 Overview
This project is a learning resource for students starting with C programming. It covers:

Input and output operations

Conditional logic (if-else, switch)

Arrays and pointers

Functions and modular code design

Structures and typedef usage

Searching and sorting algorithms

Stack and queue implementations

Dynamic memory allocation (malloc, calloc, free)

🗂 Programs Included
Some of the programs in this repository include:

Odd or Even Number Checker – Determines if a number is odd or even.

Greeting Function – Demonstrates function definition and usage.

1D Array Traversal – Iterates through and displays elements of a 1D array.

2D Array Traversal – Iterates through and displays elements of a 2D array.

Accessing Array Using Pointer Arithmetic – Shows how pointers can be used to access array elements.

Insertion Sort – Sorts an array using insertion sort algorithm.

Bubble Sort – Implements bubble sort algorithm.

Linear Search – Searches for an element using linear search.

Binary Search – Searches for an element using binary search.

Stack Operations – Implements stack using arrays.

Queue Operations – Implements queue using arrays.

Dynamic Memory Allocation – Demonstrates malloc and calloc.

Structures in C – Programs to define, access, and use structures (including nested structures and typedef).

Student Grade Calculator – Computes grade based on total marks.

Employee Structure with typedef – Demonstrates typedef with structures.

Book Search using Array of Pointers to Structure – Implements binary search with structures.

Time Table Program – Displays a timetable using switch case.

Basic Calculator – Performs arithmetic operations without using switch.

Password Validation – Simple alphanumeric password validation.

Programs for Circle Area, Student Records, and File Handling – Demonstrates practical applications of C.

(And many more — see repository for the full list.) 

🚀 How to Run
Clone the repository:

bash
git clone https://github.com/kakunopani-ctrl/Codes-for-C-Program.git
Navigate to the folder:

bash
cd Codes-for-C-Program
Compile any program using gcc:

bash
gcc filename.c -o output
Run the compiled program:

bash
./output
